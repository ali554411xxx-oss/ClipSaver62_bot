## ⚙️ إعدادات الأداء

| الإعداد | القيمة | الوصف |
|---------|--------|-------|
| `concurrent_fragment_downloads` | **16** | أجزاء متوازية لكل فيديو |
| `http_chunk_size` | **10 MB** | حجم كل جزء |
| `max_concurrent` | **1-10** | عدد الفيديوهات المتزامنة |
| `retries` | **10** | عدد المحاولات عند الفشل |

## 🔧 المتطلبات

- Python 3.8+
- `yt-dlp` — محرك التحميل
- `rich` — الواجهة الجميلة
- `ffmpeg` (مستحسن) — دمج الصوت والفيديو

### تثبيت ffmpeg
```bash
# Windows (winget)
winget install ffmpeg

# macOS
brew install ffmpeg

# Linux
sudo apt install ffmpeg
```
